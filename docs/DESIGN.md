# Identidade e composição

Direção: editorial de streetwear com contraste, proporções amplas e uma base discreta para as peças. A arte original enviada pelo responsável foi preservada como logo e referência de marca. Não foi redesenhada.

| Elemento | Regra |
|---|---|
| Base | Branco `#FFFFFF`, preto `#111111`, superfície `#F3F3F1`, linha `#DEDEDB` |
| Tipos | Barlow Condensed para títulos; Manrope para leitura e interface |
| Estrutura | Conteúdo até 1440 px; quatro colunas no desktop, duas no mobile |
| Formas | Cantos retos, divisões finas e pouca sombra |
| Hierarquia | Imagem → nome → preço → variação → entrega → compra |
| Ações | Botões de alto contraste, foco visível, área confortável para toque |
| Imagens | WebP, tamanhos definidos, variantes responsivas e lazy loading |
| Movimento | Hover leve e transições curtas; respeita `prefers-reduced-motion` |
| Feedback | Estados vazios, carregamento, erro, confirmação e indisponibilidade explícitos |

A home traz campanha configurável, novidades, categorias, lookbook, curadoria, social e VN List. O catálogo concentra busca, filtros em URL e ordenação. No mobile, os filtros abrem em um drawer acessível. A imagem editorial mobile recebe enquadramento próprio.

O hero e as imagens de demonstração foram gerados para este projeto. A grade original de seis peças foi separada em arquivos individuais e otimizada. Essas fotografias não representam produtos ou estoque reais. Substitua-as por fotografias reais ao publicar seu catálogo.

Fontes: arquivos distribuídos pelos pacotes `@fontsource`; licenças correspondentes permanecem em seus pacotes. Logo: fornecido pelo usuário. Benchmark: observado para hierarquia comercial, sem copiar código, fotos ou identidade da loja de referência.
